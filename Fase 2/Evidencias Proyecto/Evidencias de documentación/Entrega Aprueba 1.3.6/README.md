# Documentación vigente de Aprueba

La entrega 1.3.6 corresponde a la revisión de aplicación 9473b68. Las carpetas por sprint y las evidencias con fecha describen sus respectivos hitos.

- [Manual de usuario](Aprueba_Manual_usuario_detallado.pdf) para registro, práctica, facsímil, Arena, comunidad y suscripciones.
- [Manual técnico](Aprueba_Manual_tecnico_detallado.pdf) para instalación, reglas, publicación y diagnóstico.
- [Informe del equipo](Informe_Final_Aprueba_App_7.2.pdf) con el apartado 7.2 y el estado de noviembre.
- [Mapa de wireframes web y móvil](Wireframes/Mapa-Aprueba.html) para presentar las pantallas con datos de ejemplo. Descarga el archivo y ábrelo en el navegador. Las vistas individuales también se incluyen.

Los tres documentos tienen copia editable en Word. Las cifras del banco y de pruebas automatizadas se refieren a la versión de la entrega. Los presupuestos, actas y evaluaciones conservan las cifras de la fecha en que fueron producidos.
