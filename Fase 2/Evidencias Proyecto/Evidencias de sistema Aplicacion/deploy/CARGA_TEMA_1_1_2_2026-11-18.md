# Carga de sesión y transición de tema · 1.1.2

18 de noviembre de 2026, Chile.

Durante la restauración de sesión web se dibuja la misma estructura de lateral, cabecera y contenido que al terminar. El logo permanece visible; los nueve lugares del menú, avatar, nombre, plan y controles de cabecera usan placeholders. No se renderizan enlaces de navegación privados ni valores de perfil antes de resolver la sesión. Las pantallas de verificación y onboarding conservan su carga de formulario. No se modifican autenticación, permisos ni almacenamiento de sesión.

El tema web usa una revelación circular de 480 ms desde el botón. Al cambiarlo desde Ajustes sin origen de puntero se usa un punto predeterminado. En navegadores sin View Transitions se interpolan colores durante 320 ms; con movimiento reducido se omite la transición. El tema guardado se aplica antes de arrancar React para evitar el destello claro tras F5. Los cambios de perfil se aplican cuando el servidor confirma el guardado. Los errores no desplazan el botón ni cambian el tema.

Flutter usa una transición de 420 ms y una ThemeExtension para interpolar los colores personalizados, además de los de Material. Respeta desactivación de animaciones del dispositivo. Mantiene el almacenamiento y guardado de preferencias existentes. Android 1.1.2+202611181.
