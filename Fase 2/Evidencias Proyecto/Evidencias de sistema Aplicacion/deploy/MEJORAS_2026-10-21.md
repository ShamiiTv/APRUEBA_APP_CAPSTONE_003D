# Mejoras de Aprueba · cierre 22-10-2026

## Referencia y alcance

Se revisaron Aprueba_Wireframe.html, Aprueba_App.html y Aprueba_Web_Wireframe.html de apruebavistas.zip. Sus originales están en las evidencias de documentación, Requisitos/Wireframes Alloxentric 2026-10-21. Se usaron como referencia funcional, conservando el tema, tipografías, navegación e iconos del proyecto del equipo.

- Web: https://aprueba.shamiiplay.com/
- Móvil en navegador: https://aprueba.shamiiplay.com/movil/
- Ambas interfaces utilizan la misma API y Firebase real, proyecto aprueba-app-9d317.
- Se conserva HTTPS y la configuración de Nginx. No se modificó Copa Kick.

## Límites y dependencias externas

- SMS no se activó: Firebase exige facturación Blaze para enviar códigos. Se respetó la preferencia de usar correo sin activar gastos.
- Facebook está deshabilitado visualmente hasta que se configure su aplicación/proveedor y credenciales. No se presenta una vinculación ficticia.
- La aprobación final de OAuth Google por una persona y la recepción del correo en una casilla real requieren una prueba manual. Se comprobó la creación real de la sesión de vinculación y el rechazo de contraseña incorrecta; no se controló una cuenta Google personal ni se enviaron mensajes a otras personas.
- La vinculación social implementada en Flutter corresponde a su versión web. El adaptador nativo informa que se use la web; no se entregó ni probó un APK/IPA.
- Actualmente las 1.360 preguntas publicadas son intermedias. No se reclasificaron automáticamente ni se inventaron preguntas básicas/avanzadas. El banco mantiene 1.419 documentos y 59 pendientes de revisión. Historia aún no tiene contenido publicado.
- El catálogo comercial de beneficios debe ser suministrado por Alloxentric. Con la regla 5:1, cinco platinos equivalen a 3.125 bronces; el banco actual no permite conseguirlos solo con primeras respuestas de un alumno. Esta economía requiere validación de negocio; los regalos permiten transferir saldos existentes, no crear medallas.
- La verificación de correo se ofrece desde perfil; no se añadió un bloqueo general de práctica para cuentas antiguas sin verificar.

## Validación

- 58 pruebas unitarias API aprobadas.
- 31 pruebas de integración en Firestore Emulator aprobadas: práctica 9, social 10, medallas 6 y mejoras 6.
- 6 pruebas web y lint aprobados; build de producción generado con API relativa /api/v1.
- 6 pruebas Flutter aprobadas; flutter analyze sin incidencias y build web generado para /movil/ con el dominio nuevo.
- En la VPS se comprobaron registro, onboarding, cuotas 10/15/20, grupos públicos/privados, invitación, siete respuestas correctas, regalo sin duplicado, canje y plan de una prueba con alcance correcto.
- Navegador real: cambio a inglés, medallas, grupos, tutores y precios web; login móvil compartido, perfil y planes móviles. La pantalla móvil de regalos recibió HTTP 200 y se verificó visualmente el destinatario; una limitación de su árbol de accesibilidad afectó el selector automático y motivó mejorar las etiquetas.
- Las cuentas y grupos temporales se eliminaron al finalizar. Dos recorridos guardaron siete respuestas cada uno: los contadores agregados de esas preguntas aumentaron, sin sobrescribir actividad concurrente.

## Operación y continuidad

Se mantienen las cachés del banco de seis horas y de historial por usuario de 60 segundos, además de los reintentos automáticos Flutter deshabilitados ante errores. No se ejecutaron seeds ni se activó facturación Firebase.

PAYMENTS_MODE=simulation se configura en un override del servicio aprueba-api; al retirar ese modo, los derechos simulados dejan de habilitar práctica ilimitada. No se registran pagos reales.

El instalador Install-ApruebaImprovements.sh respalda código y web antes de actualizar y restaura ante fallo de salud. No modifica TLS ni claves. Respaldo anterior a la corrección de firma: /opt/shamii/aprueba-backups/improvements-20261021-222001.tar.gz.

Para futuros despliegues conjuntos, Update-Aprueba.ps1 admite -IncludeMobile -FlutterPath ruta/a/flutter.bat. Sin ese parámetro conserva la versión móvil remota. Build-ApruebaMobile.ps1 utiliza la URL canónica y sincroniza el script compartido de vinculación social.

Cierre del despliegue: último ajuste visual y de accesibilidad publicado sin reiniciar la API. Los hashes de index.html y main.dart.js coinciden con las compilaciones locales. Salud HTTPS: ok, Firebase conectado; API, Nginx y torneos activos. Respaldo final de interfaz: /opt/shamii/aprueba-backups/final-ui-20261022.tar.gz.
